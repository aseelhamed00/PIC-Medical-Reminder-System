# PIC Medical Reminder System

An embedded medical reminder system implemented in PIC Assembly using MPLAB.

The project is designed to help users remember scheduled medication times using a PIC microcontroller-based system.

## Features

- Implemented in PIC Assembly
- Medication reminder functionality
- Time-based reminder logic
- Embedded-system control using PIC registers and instructions
- Designed and tested using MPLAB tools
- Low-level hardware-oriented implementation

## Technologies

- PIC Microcontroller
- Assembly Language
- MPLAB
- Embedded Systems

## Project Files

```text
main.asm
Medical_Reminder.mcp
.gitignore
README.md
```

### `main.asm`

Contains the main Assembly implementation of the medical reminder system.

The code includes the system logic, register configuration, control flow, timing behavior, and reminder functionality.

### `Medical_Reminder.mcp`

MPLAB project file used to organize and build the project.

## Build Environment

This project was developed using Microchip MPLAB.

To build the project:

1. Open the MPLAB project.
2. Load `Medical_Reminder.mcp`.
3. Build the project using the configured PIC target.
4. Use the generated output file for simulation or programming the target microcontroller.

## Generated Files

Build-generated files such as:

```text

*.cof
```

are excluded from the repository because they can be regenerated from the source code.
